  <name>Task 1: Add Twitter two-step publishing to ScheduledPostWorker</name>
  <files>server/lib/clippster_server/social/scheduled_post_worker.ex</files>
  <action>
Modify the `do_publish/3` function in ScheduledPostWorker to handle Twitter's two-step flow (upload media then create tweet), while preserving the existing Instagram behavior.

Current `do_publish/3` calls `Platform.call(platform, :publish_media, ...)` and expects `{:ok, %{post_id, post_url}}` back. This works for Instagram where publish_media returns the final post. For Twitter, publish_media returns `{:ok, %{media_id: media_id}}` and needs a second step.

Replace the single `do_publish/3` with pattern-matched clauses:

1. **Twitter clause** (`%PostSubmission{platform: "twitter"}`):
   - Step 1: Call `Platform.call("twitter", :publish_media, [access_token, post.media_url, publish_opts])` to upload media
   - On `{:ok, %{media_id: media_id}}`: proceed to step 2
   - Step 2: Call `Platform.call("twitter", :create_tweet, [access_token, post.caption || "", [media_ids: [media_id]]])` to create tweet
   - On `{:ok, result}`: call `handle_publish_success(post, result)` (result has post_id and post_url)
   - On `{:error, reason}` at either step: call `handle_publish_failure(post, inspect(reason), classify_error(reason))`
   - Log each step: "[ScheduledPostWorker] Twitter: uploading media for post #{post.id}" and "[ScheduledPostWorker] Twitter: creating tweet with media_id #{media_id}"

2. **Default clause** (all other platforms including Instagram - existing behavior):
   - Keep current implementation exactly as-is: single `Platform.call(post.platform, :publish_media, ...)` that returns `{:ok, %{post_id, post_url}}`

The `publish_opts` for Twitter media upload should include: `%{filename: "video.mp4", ig_user_id: get_platform_user_id(account)}` (ig_user_id is used generically for platform_user_id).

Important: Do NOT change handle_publish_success, handle_publish_failure, classify_error, get_org_account, get_user_account, or any other existing functions. Only modify do_publish/3 by splitting it into two clauses.

2. **Default path** (all other platforms including Instagram):
   - Keep existing implementation exactly as-is

The existing PulseKit capture pattern should be preserved for both success and failure cases. Use the same metadata structure as the current implementation.

Important: Do NOT change any other functions in the controller. Only modify publish_to_platform/3.
