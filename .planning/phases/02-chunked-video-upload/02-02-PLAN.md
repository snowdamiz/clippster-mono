  <name>Task 2: Implement Twitter.publish_media/3 with chunked upload and R2 presigned URLs</name>
  <files>server/lib/clippster_server/social/platforms/twitter.ex</files>
  <action>
Replace the stub `publish_media/3` in twitter.ex with a working implementation that:

1. **Add alias at top of module** (after require Logger):
   ```
   alias ClippsterServer.Social.TwitterChunkedUpload
   alias ClippsterServer.Storage
   ```

2. **Replace publish_media/3** (currently returns `{:error, :not_implemented}`):

   The function receives `(access_token, media_url, opts)` where:
   - `access_token` is the user's X OAuth token
   - `media_url` is the URL of the video (could be R2 URL, public URL, or local path)
   - `opts` is a map with optional keys: :caption, :media_type, :filename, :duration_seconds

   Implementation flow:
   a. Generate presigned URL if media_url is an R2 URL (contains ".r2.cloudflarestorage.com"):
      - Call `Storage.presigned_url(media_url, expires_in: 21_600)` (6 hours -- long enough for X processing per research pitfall #7)
      - Use presigned URL for download, log that presigned URL was generated
      - If presigned URL generation fails, log warning and try original URL

   b. Fetch the video binary from the accessible URL:
      - Call `HTTPoison.get(accessible_url, [], [timeout: 120_000, recv_timeout: 120_000, follow_redirect: true])` with longer timeout for large files
      - On success (200), extract body as binary
      - On failure, return `{:error, {:download_failed, status_or_reason}}`

   c. Call `TwitterChunkedUpload.upload_video(access_token, video_binary, upload_opts)` where upload_opts includes filename and duration_seconds from opts if present

   d. On success, return `{:ok, %{media_id: media_id}}` -- Note: this is slightly different from Instagram's publish_media which returns post_id/post_url. For X, media upload and tweet creation are separate steps (Phase 3 handles tweet creation). Return just the media_id so Phase 3's tweet creation can attach it.

   e. On failure, return `{:error, reason}` propagating the error from TwitterChunkedUpload

3. **Add a private helper** `fetch_video_binary(url)`:
   - Downloads video from URL
   - Returns `{:ok, binary}` or `{:error, reason}`
   - Uses 120-second timeouts (videos can be large)
   - Follows redirects (presigned URLs may redirect)

4. **Logging:** Use `Logger.info("[Twitter] ...")` prefix consistent with existing twitter.ex patterns. Log: presigned URL generation, download start/complete with size, upload start, upload complete with media_id, errors.

IMPORTANT: Do NOT modify the `@impl true` annotation -- this is still a Platform behaviour callback. The return type changes from `{:error, :not_implemented}` to `{:ok, %{media_id: media_id}}` which is compatible with the `{:ok, map()}` spec.
  </action>
