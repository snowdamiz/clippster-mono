# AI Video Creator - User Prompt Guide

## 🎯 How to Write Effective Prompts

The AI Video Creator works best when you give it clear, specific instructions. Here's how to get the best results:

---

## 📝 Basic Prompt Structure

```
[Action] + [Style/Mood] + [Specific Elements]
```

### Example:
```
Create an exciting gambling highlight with bold captions, 
zoom effects on big moments, and flash effects when wins happen
```

---

## 🎬 Prompt Templates

### 1. **Gambling/Casino Content**
```
Transform this gambling clip into a hype moment:

Text:
- Use the exact words from the video
- Highlight dollar amounts in gold/yellow
- Large captions at bottom with black outline
- Show each caption for 1-2 seconds throughout the video

Camera:
- Slow zoom in during suspense
- Quick punch zoom when result appears
- Subtle shake during reactions

Effects:
- White flash (0.2s) when win/loss revealed
- Screen shake on big reactions
- Glow effect during peak moments

Style:
- Dark vignette around edges
- Boost colors for energy
- Modern TikTok/Shorts style
```

### 2. **Gaming Highlights**
```
Make this gaming clip viral-ready:

Captions:
- Use actual dialogue from the video
- Emphasize key callouts and reactions
- Position at bottom, large and bold

Motion:
- Zoom in on clutch moments
- Pan to follow action
- Shake on eliminations

Effects:
- Flash on kills/victories
- Glow on ultimate abilities
- Quick cuts feel with camera motion

Style:
- High contrast
- Vibrant colors
- Fast-paced energy
```

### 3. **Reaction Content**
```
Create an engaging reaction video:

Text:
- Caption the exact reactions and commentary
- Emphasize emotional words (WOW, NO WAY, etc.)
- Keep text synced with speech

Camera:
- Slow zoom during build-up
- Quick zoom on reaction peaks
- Hold steady during talking

Effects:
- Flash on surprise moments
- Subtle glow during excitement
- Minimal shake for emphasis

Style:
- Clean and readable
- Focus on the reaction
- Professional but fun
```

### 4. **Tutorial/Educational**
```
Make this tutorial engaging:

Captions:
- Use exact spoken words
- Highlight key terms and numbers
- Clear, readable text throughout

Motion:
- Slow, smooth zooms
- Pan to important areas
- Minimal shake (professional feel)

Effects:
- Subtle glow on important points
- No flash (too distracting)
- Smooth transitions

Style:
- Clean and professional
- High readability
- Consistent pacing
```

### **Text/Captions**

## ❌ Common Mistakes to Avoid

### ❌ Too Vague
```
Make it cool
```
**Why it's bad:** AI doesn't know what "cool" means to you

### ✅ Better
```
Add zoom effects, bold captions, and flash on big moments
```

---

### ❌ Conflicting Instructions
```
Make it subtle but with intense effects
```
**Why it's bad:** Contradictory instructions confuse the AI

### ✅ Better
```
Use subtle camera motion but intense flash effects on key moments
```

---

### ❌ No Timing Context
```
Add captions
```
**Why it's bad:** AI doesn't know when or how many

### ✅ Better
```
Add captions throughout the entire video using the exact spoken words
```

## 🔄 Iterative Editing

After generating your first video, you can refine it with follow-up prompts:

### First Prompt:
```
Create a gambling highlight with captions and zoom effects
```

### Follow-up Prompts:
```
Make the text bigger
```
```
Add more flash effects
```
```
Change the vignette to 50% opacity
```
```
Remove the camera shake
```

## 🎨 Style Keywords

Use these keywords to quickly set the mood:

- **Viral**: Fast-paced, bold, high energy
- **Professional**: Clean, smooth, subtle
- **Hype**: Intense, dramatic, lots of effects
- **Minimal**: Simple, clean, few effects
- **Retro**: Vintage colors, old-school effects
- **Modern**: Sleek, smooth, contemporary
- **Cinematic**: Slow motion, dramatic, film-like

---

## 📊 Effect Intensity Guide

- **Subtle**: 0.1-0.2 intensity
- **Moderate**: 0.3-0.4 intensity
- **Strong**: 0.5-0.7 intensity
- **Extreme**: 0.8-1.0 intensity

---

## 🚀 Pro Tips

1. **Always specify "use exact words"** if you want accurate captions
2. **Mention timing** (throughout video, at beginning, at end)
3. **Layer effects** (flash + shake + zoom = maximum impact)
4. **Test and iterate** - start simple, then refine
5. **Reference styles** (TikTok, YouTube, Instagram) for quick context
6. **Be specific about colors** (gold, white, red) not just "colorful"
7. **Specify positions** (bottom, top, center) for text placement

## 📞 Need Help?

If your video isn't coming out right:

1. **Check your clip has transcript data** - captions need this
2. **Be more specific** - add details about timing and intensity
3. **Use iterative prompts** - refine step by step
4. **Reference the templates** - start with a proven structure
5. **Describe the mood** - help the AI understand your vision

---

**Remember:** The AI works best with clear, specific instructions. Don't be afraid to be detailed!
